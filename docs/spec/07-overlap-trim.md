# 7. 截斷重疊

## 目的

上游把踏板延音寫進音長（第 1 章），同一隻手的音因此互相重疊，譜面上變成一堆長音與連結線。本步驟依規則提前音尾，減少譜面重疊；可選擇依踏板狀態限制估計止音點的提前量，不保證播放聲音完全不變。

程式：`src/trim_overlaps.py`。在分手之後執行，直接覆寫 `song_bpmfix_cleaned.mid`。

只移動音尾：不刪音、不改起音、音高、力度，也不改踏板。

## 整體結構

截斷分兩層：

1. **候選規則**提出「這顆音可以在哪裡結束」。真正的放鍵時間不在 MIDI 裡，規則只能從演奏結構推測。
2. **可選的踏板限制**判斷這個候選會不會讓聲音提前停止；啟用時超過容差就拒絕。

所有規則共用 `release()` → `PedalGuard.allow()`。面板的「依踏板狀態限制截斷」預設關閉；`postprocess.py`、`trim_overlaps.py` 的命令列及 Python API 預設開啟，命令列用 `--no-pedal-protection` 關閉。關閉時略過止音點容差及事件不明的拒絕判斷，候選規則與門檻不變。一顆音被多條規則提出時，以最早被接受的截斷點為準。

## 前提

- 每隻手（聲道）分開處理；起音相差 50 ms 內的音為同一組。
- 快速音群與跨節拍線兩條規則使用拍子網格（`ticks_per_beat`），輸入須已做 BPM 修正與第一拍對齊（第 2 章）。
- 分手時踏板已複製到各手的聲道（第 6 章）。

## 候選規則

依執行順序：

| 規則 | 適用 | 條件 | 截在 |
|---|---|---|---|
| 快速音群 | 預設右手、第二右手 | 連續 3 組以上起音、每組間隔 ≤ 0.5 拍；音群內每組的音 | 同手下一組起音 |
| 外聲部銜接 | 兩手 | 新組的最外側音（右手最高、左手最低）與仍按著的最外側音相差 ≤ 2 半音，像音階往前走 | 新起音 |
| 換和聲 | 兩手 | 這個時刻所有手合起來有 ≥ 3 個不同音名；仍按著、音名不在其中的音 | 新起音 |
| 換和弦 | 兩手 | 這隻手彈新的和弦（≥ 2 個音）；上一個和弦仍按著的音 | 新起音 |
| 按鍵需求過大 | 兩手 | 仍按著的音加新音超過 5 個不同音高，或跨度超過 14 半音；仍按著的全部音 | 新起音 |
| 跨節拍線 | 兩手 | 新起音距最近節拍線 ≤ 1/8 拍；仍按著、跨過該線、且在線前超過 1/4 拍起音的音 | 新起音 |

「仍按著」以目前的音尾判斷：被保護拒絕的音繼續參與後面的判斷。

快速音群在左手預設關閉，因為它也會截掉分解和弦下按著的低音（`--fast-figure-hands` 可開啟）。

跨節拍線的「線前 1/4 拍內起音不算」，用來排除略早彈的正拍音。

## 踏板保護

### 推算聲音何時停

依同聲道 CC64（127 踩、0 放）：

- 放鍵時踏板踩著：聲音延到下一次鬆踏板。
- 放鍵時踏板沒踩：聲音在放鍵時停。
- 踏板踩下後一直沒鬆開：延到檔案結尾。
- 踏板事件與音尾在同一 tick、先後不明：原音尾取較晚的解讀，候選取較早的解讀。

### 接受條件

全部成立才截斷：

- 候選在起音之後。
- 候選的聲音停止時間比原音尾的提前不超過 `SUSTAIN_TOLERANCE_SECONDS`（0.1 秒）。有沒有踏板都適用。
- 同音高沒有其他音與 [候選, 原音尾] 重疊。
- 該聲道沒有：半踏板值（CC64 不是 0 或 127）、CC66、CC69、channel mode 控制（CC120–127）、配不成對或重疊的音符事件。有任何一項，整個聲道都不截。

一律與原始音尾比較，同一顆音被截多次，累積的提前量也不超過容差。

### 容差的依據

8 首測試曲中，轉譜音尾集中在鬆踏板之後 0–100 ms，超過 100 ms 回到背景水準；上游音尾的精度也在約 100 ms 量級（第 1 章）。0.1 秒涵蓋這段估計偏差；再放寬多半只會納入與鬆踏板無關的音。

原音尾比鬆踏板晚幾十毫秒時，縮短這段可能減少重複記錄的延音；是否更接近原錄音仍須聽感確認，不能只由容差數值判定。

沒有踏板時，0.1 秒容差的依據只是一般連奏重疊較短，尚未經試聽確認。

## 寫回

- 只移動被接受的音尾；同一 tick 時被移動的音尾排在其他事件之前，其餘事件的絕對時間與相對順序不變。
- 沒有任何截斷被接受時不重寫檔案。

## 已知限制

- **上游踏板可能放錯**：截斷以 MIDI 踏板判斷聽感。上游的踏板模型與音符模型分開估計，踏板可能提早放開，而音符仍被判斷為響著；此時保護會拒絕截斷，結果偏保守。在 La la 勇気のうた 中，跨節拍線且被拒絕的有 335 次，改用另一模型的踏板判斷，多數在容差內。目前沒有可靠的方法判斷踏板是否放錯。
- 規則推測的是放鍵時間，沒有真值；以 Transkun 音尾作參考的吻合度見 `docs/pedal-aware-trimming-plan.md` 第 9 節。
- 處理後不保證每手同時按鍵數與跨度都在限制內。
- 聽感依 MIDI 語義推算，尚未系統性驗證；釋放聲、共鳴等音源行為不在推算內。勇氣歌的新版／舊版比較中，使用者偏好舊版，正式 MIDI 已恢復舊版，見 `docs/lala-bytedance-transkun-comparison.md`。
- 截斷後重跑分手不會恢復音長；要回到截斷前，從 `song_bpmfix.mid` 重建。
