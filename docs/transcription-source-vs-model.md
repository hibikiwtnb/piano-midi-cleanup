# 音源與轉譜模型對 MIDI 的影響

2026-10-21，以 La la 勇気のうた 比較。機器是 Intel iMac Pro，只用 CPU。

## 比較對象

| 代號 | 音源 | 鋼琴分離 | 轉譜模型 |
|---|---|---|---|
| A | m4a（有損，2024） | 舊版 lalal.ai | Pianotrans |
| B | HiRes FLAC（24bit / 48kHz） | lalal.ai v6 | Pianotrans |
| C | 同 B | 同 B | Transkun V2（2.0.1，No Pedal Ext） |

三份 MIDI 的第一個起音都在 6.775 秒，曲長一致，不需要平移就能比較。

## 起音吻合度

起音相差 50ms 以內算對上，F 值是雙向命中率的調和平均。

| 比較 | 改變了什麼 | F |
|---|---|---:|
| A 對 B | 音源與分離模型，轉譜模型相同 | 0.760 |
| B 對 C | 只換轉譜模型 | **0.921** |
| A 對 C | 全部都換 | 0.759 |

## 結論

- 音源這一端（音質加鋼琴分離）的影響遠大於轉譜模型。只換模型時九成以上的音一致；換了音源，吻合度就掉到和全部都換差不多。
- A 對 B 同時換了音質（m4a 換成 HiRes）和分離模型（lalal.ai 舊版換成 v6），這次比較分不開兩者。
- 音源造成的差異集中在中音 C 以上：B 比 A 少了約 280 個中音 C 以上的音，中音 C 以下的音數差不多。
- F 值只代表兩份 MIDI 一致的程度，不代表哪一份比較準。沒有正確答案可以對照，要判斷準確度還是得聽或看譜。
- 想改善轉譜，先拿到乾淨的鋼琴分離音軌最重要，換轉譜模型只是小幅修正。

## 模型差異細節

| 項目 | A 舊版 Pianotrans | C Transkun V2 |
|---|---:|---:|
| 音符數 | 3113 | 2733 |
| 中音 C 以上 / 以下 | 2207 / 906 | 1850 / 883 |
| 時值中位數 | 426ms | 97ms |
| 短於 50ms 的音符 | 2.8% | 22% |
| 最大同時發音數 | 20 | 9（依踏板延長後是 20） |
| 延音踏板踩下次數 | 212 | 177 |

- 同一份音源，Transkun 比 Pianotrans 多辨識出約 4% 的音，Pianotrans 則有約 10% 的音 Transkun 沒有。
- Transkun V2 的音尾是手指放開琴鍵的時間，不會依延音踏板延長，所以短音很多。這些短音力度正常（平均 67），大多是真的音。
  - 因此 `midi_stats` 的「極短音符」比例，不能拿來比較這兩種模型。
  - `clean_midi_rules` 的「時值短於 30ms」規則，在 Transkun 輸出上只刪掉 29 個音。
- 這首 4 分 16 秒的歌，CPU 轉譜時間：Transkun 約 91 秒，Pianotrans 約 3 分鐘。
- Pianotrans 的最後一個音結束在 258.8 秒，比音檔的 256.1 秒還長，是最後一個踏板延長造成的。
