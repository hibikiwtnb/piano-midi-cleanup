# 使用者回饋

## 第 21 小節：刪音取捨應考慮音群的可彈性

- 日期：2026-10-23。
- 狀態：已逐音核對，刪音評分尚未修改。
- 曲目與位置：`A song for You! You? You!!`，第 21 小節第 1 拍；原始回饋後的核對詳見 [策略討論](playable-removal-strategy.md)。

### 使用者觀察

第 21 小節目前刪除了 B3，但使用者認為刪除 E5 更合適。B3 更接近既有音群，保留它較容易讓同一隻手一起彈奏。

### 希望改善的行為

刪音取捨應考慮保留後的音群是否緊湊、是否容易分配給雙手，避免只因音域較高就優先保留 E5，反而刪除更容易納入手位的 B3。

### 後續檢查方向

- 已確認是可彈性清理的刪音成本所致，並比較「刪 B3、留 E5」與「留 B3、刪 E5」的可行分法；具體音群及成本見策略討論。
- 若調整雙手簡化的取捨，考慮保留後的音群緊湊程度，同時注意 E5 是否具有旋律作用。
- 本案例的期望是優先保留 B3；不能直接泛化為一律刪除較高或較遠的音符。
