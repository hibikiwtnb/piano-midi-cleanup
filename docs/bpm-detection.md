# BPM 偵測的可靠度

BPMFix 用 Essentia 偵測 BPM，再用半拍解析度的相位一致性估計實際速度。實作在 `src/bpmfix_utils.py`。

## 為什麼不直接用 Essentia 的值

- Essentia 的原始值常偏離整數 0.1 BPM 以上。
- 直接拿拍點做線性擬合不可靠：拍點追蹤中途會跳到反拍，擬合結果會偏 0.1 到 3 BPM。
- 所以改用相位一致性估計實際 BPM，再看取整後的曲尾漂移（`曲長 × |估計 BPM / 套用 BPM - 1|`）：
  - 漂移在 50ms 以內，套用整數 BPM。
  - 超過 50ms，保留兩位小數。
  - 門檻是 `ROUND_MAX_END_DRIFT_MS`。

## 音源對偵測的影響（La la 勇気のうた，實際 135）

| 音源 | Essentia 原始值 | 相位估計 | 一致度 | 曲尾漂移 |
|---|---:|---:|---:|---:|
| HiRes FLAC | 135.0064 | 134.9964 | 0.924 | 7ms |
| 舊 m4a | 135.1427 | 134.9962 | 0.900 | 7ms |
| lalal 鋼琴分離音軌 | 135.1260 | 134.9980 | 0.765 | 4ms |

- 三種音源都正確取整成 135，音質對 BPM 偵測幾乎沒影響。
- 鋼琴分離音軌的一致度較低，推測是因為沒有鼓。偵測 BPM 時用原曲或伴奏比較穩。

## 一致度是可信度的指標

2026-10-22 測試曲的結果：

| 曲 | 套用 BPM | 一致度 | 結果 |
|---|---:|---:|---|
| CRYCHIC 春日影 | 97 | 0.933 | 正確 |
| 告白日和、です! | 86 | 0.969 | 正確 |
| 嵐のなかの恋だから | 145 | 0.899 | 正確 |
| 月夜見海月 | 140 | 0.966 | 正確 |
| なってしまった!（μ's） | 171.48 | **0.045** | 錯誤，實際是 170 |

- 一致度低於約 0.5 時，偵測到的 BPM 不可信，要手動確認，再用 `bpmfix.py --bpm` 重跑。
- 一致度很低時，取整的漂移判斷也會跟著錯（なってしまった 的漂移顯示 7ms，看起來沒問題）。
- 目前報告只寫出一致度數值，不會另外警告。
